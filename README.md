# SWELL子テーマ CSS分割版

## 📁 ファイル構成

```
swell_child/
├── css/
│   ├── base.css        (262行)  - 全ページ共通スタイル
│   ├── front-page.css  (2,105行) - トップページ関連スタイル
│   └── single.css      (5,139行) - 店舗詳細・アーカイブ関連スタイル
├── functions.php                 - CSS読み込み処理（更新済み）
├── style.css                     - テーマ情報のみ（CSSは空）
└── [その他テンプレートファイル]
```

## 🚀 インストール方法

### 方法1: 完全入れ替え（推奨）

1. **バックアップを取る**
   - 現在の子テーマフォルダを丸ごとバックアップ

2. **ファイルを入れ替え**
   - 新しいファイルをFTPでアップロード
   - または、サーバーのファイルマネージャーで置き換え

3. **キャッシュをクリア**
   - SWELL設定 → キャッシュ削除
   - ブラウザのキャッシュも削除

### 方法2: 手動でファイルを配置

1. `css/` フォルダを子テーマ直下にアップロード
2. `functions.php` を置き換え
3. `style.css` を置き換え

## ⚠️ 重要な注意点

### CSS編集時の注意

| 編集したい内容 | 編集するファイル |
|---------------|-----------------|
| 変数、ヘッダー、フッター、フォント | `css/base.css` |
| トップページ（ヒーロー、エリア選択等） | `css/front-page.css` |
| 店舗詳細、ランキング、一覧ページ | `css/single.css` |
| 緊急の上書き（一時的な修正） | `style.css` |

### 読み込み順序

```
1. 親テーマ（SWELL）のスタイル
2. base.css
3. front-page.css
4. single.css
5. style.css
```

後に読み込まれるファイルが優先されます。

## 🔧 カスタマイズ例

### 新しいスタイルを追加する場合

```css
/* css/single.css の末尾に追加 */

/* --- 追加: カスタムスタイル --- */
.my-custom-class {
    color: red;
}
```

### パフォーマンス最適化（上級者向け）

サイトが安定したら、functions.phpのコメントアウトされている「パフォーマンス最適化版」を有効にすることで、
各ページに必要なCSSのみを読み込むことができます。

## 📝 変更履歴

- 元の `style.css` (7,449行) を3ファイルに分割
- 重複スタイルはCSSカスケードルールに従い最新のもののみ保持

## ❓ トラブルシューティング

### Q: デザインが崩れた
1. ブラウザキャッシュを完全にクリア（Ctrl+Shift+Delete）
2. SWELL設定からキャッシュを削除
3. 元のstyle.cssに戻して比較

### Q: 一部のスタイルが効かない
1. ブラウザの開発者ツール（F12）でCSSが読み込まれているか確認
2. `functions.php` が正しくアップロードされているか確認
