## 追加・確認したいACF項目

| 優先 | 項目 | 入力方針 |
|---|---|---|
| 高 | `shop_ai_summary` | 下記の個別コメントを登録。体験談調にしない |
| 高 | `basic_price` / `price_textarea` | 0円は禁止。未確認は「公式サイト確認中」または「要確認」 |
| 高 | `official_url` | 公式サイトが確認できる店舗は必ず登録 |
| 高 | `shop_hours` | 最終受付が分かる場合は営業時間と分けて記載 |
| 高 | `shop_address` | 日本橋・近鉄日本橋・なんば・谷町九丁目との関係判定に使う |
| 高 | `shop_ai_summary` | 一覧では短縮表示、店舗詳細では全文表示 |
| 中 | `shop_booking` | 完全予約制・電話予約・LINE予約など |
| 中 | `shop_tel` / `shop_line` | CVボタン改善用 |
| 中 | `shop_catch` | 店舗詳細の短い補足文 |
| 中 | `shop_holiday` | 定休日 |

## 本番入力時の注意

- `review_star` は実ユーザー口コミではない場合、口コミ評価として扱わない。
- 実口コミが0件の店舗に、口コミ件数やAggregateRatingを付けない。
- `shop_today_analysis` に「本日」「今すぐ」が入っていても、取得日不明なら表示側では安全文言に変換する。
- 最終確認日は、実際に公式サイトや店舗情報を確認した日だけ入力する。
- 料金が公式未確認の場合は、`0` ではなく「公式サイト確認中」「要確認」を使う。
