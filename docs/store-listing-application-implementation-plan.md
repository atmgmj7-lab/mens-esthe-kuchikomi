# 掲載申請・承認 UI 実装計画（ローカル検証）

## 目的

未掲載店舗・掲載済み店舗の双方が使える無料の掲載申請を提供し、申請内容と連絡先を非公開で審査し、承認された公開候補だけを表示する。既存の店舗を選んでも所有権は付与しない。

## 実装順序

1. 申請ごとに短時間・一回限りの画像アップロード確認を発行し、別申請、期限切れ、再利用を拒否する。
2. 公式バナーの選択、原寸プレビュー、HTML コピー、無料ダウンロードと掲載申請フォームを `/storelisting/` に統合する。
3. 運営者向けに審査一覧・詳細・編集・差分・承認・差し戻しを、公開画面から分離して実装する。
4. 承認済み投影だけを読取り可能にし、連絡先や審査メモ、private object key は公開しない。
5. local Supabase とブラウザで承認前非公開・承認後表示・競合更新・画像拒否を検証する。

## 境界

- この計画と実装は local Supabase のみを対象とし、本番 DB／Storage／RLS／WordPress は変更しない。
- 決済、プラン変更、既存都道府県カードのレイアウト変更は含めない。
- 本番導入には別途 migration 適用、service role の保管、運営者認証・権限設定、最終レビューと明示承認が必要。
