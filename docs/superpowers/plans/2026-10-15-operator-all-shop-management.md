1. **Complete** — Added schema/repository/source contracts for immutable legacy identity, draft/public separation, revision conflict, cross-store assets, service-only RPC access, visibility, and source composition.
2. **Complete locally** — Added additive managed-directory migrations with RLS/revokes, private asset metadata, controlled visibility, and API-schema service-role wrappers. No production migration was applied.

4. **Complete** — Implemented dashboard new-store creation, legacy import-on-edit, bounded draft form, private image upload, submit/review/approve/return, and reversible publish/unpublish controls.
5. **Complete behind an opt-in flag** — Wired shop detail, list, area routes, sitemap, and count to the approved composition when `SHOP_DIRECTORY_SOURCE=supabase`; the default production source remains unchanged.
6. **Complete locally / release blocker recorded** — Local migration, transaction contracts, and real Chromium → Next → Supabase/private Storage E2E passed: existing-store import, every editable field, private banner/gallery denial, approval, public rendering, unlisting, and republishing. The composed page safely renders the framework not-found UI with no store content and the asset proxy returns 404. Cache Components/PPR still streams that UI with HTTP 200. A direct Proxy→Supabase lookup produced HTTP 404 locally but was deliberately discarded: it would issue a database RPC on normal public shop requests and is not acceptable while Vercel CPU is constrained.
7. **Pending architecture decision for true HTTP 404** — Immediate, globally invalidated HTTP 404 without per-request database work needs an existing shared edge state source (for example, already-provisioned Vercel Edge Config/KV) updated by the publish/unpublish workflow. This repository has no such configured resource. Do not provision a new paid service or claim a correct 404 until the owner confirms an existing no-new-cost source or accepts a bounded-delay cache design.
8. **Complete local gates / pending review** — Typecheck, lint, build, source/repository contracts, Partner editor regression, and E2E passed. Before a draft PR, perform one final diff review and commit only the feature files; do not deploy or alter production configuration without approval.
