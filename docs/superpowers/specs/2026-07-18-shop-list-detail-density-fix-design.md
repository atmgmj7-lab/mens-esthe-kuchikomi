# Eskomi 一覧ランキング・店舗詳細密度 再調整設計

作成日: 2026-07-18
対象: `headless/` の共通店舗一覧カードと店舗詳細
前提: 2026-07-17承認済みA案の補正。今回のユーザー指示を設計承認として扱う。
停止条件: ローカル実装・検証・独立レビュー完了後、push・本番公開前で停止する。

## 1. 目的

本番スクリーンショットで確認された次の3点を、CSSの上書きではなく画面構造から解消する。

1. ランキング順位が入ると店舗一覧の画像・店名・本文位置がずれる。
2. 店舗詳細で公式・LINE・電話など同一問い合わせ導線がPC上に二重表示される。
3. 店名、料金、営業時間、画像、余白の比率が大きく、情報ポータルとして密度が低く見える。

## 2. 採用構成

### 店舗一覧

- 順位バッジは独立列を使わず、店舗画像左上へ重ねる。
- 順位あり・なしでカードの列数と、画像・店名・本文・操作の開始位置を変えない。
- PCは `画像 / 情報 / 操作` の3列、900px以下は `店名 / 画像 / 要点 / 操作` の積み上げとする。
- バッジは画像からはみ出さず、画像リンク内の情報として読める位置に置く。
- 順位数字と「位」は同じ高さの中央揃えを維持する。

### 店舗詳細

- PC上部は `写真 / 店名・要点・予約` の2列にする。
- これまで右側にあった `AT A GLANCE` と予約群の重複領域は削除する。
- PCでは店名・要点側の予約群を1つだけ表示する。
- 760px以下では上部予約群を隠し、画面下部の固定予約群だけを表示する。同一画面幅で見える予約群は常に1つとする。
- ページ内メニューは上部2列の直後に置き、詳細セクションは本文幅全体を使う。
- 詳細セクションは `見出し / 内容` の2列を維持するが、見出し列と隙間を縮め、料金・基本情報・口コミ・近隣導線を読み進めやすくする。

## 3. 文字と余白

- 店名: PC最大34px、1024px以下30px、760px以下26px、360px以下23px。
- 上部の料金・営業時間・予約方法: PC最大18px。長い営業時間を1文字単位で分断しない。
- 本文: 15〜16px、補足: 12〜13px。
- 詳細見出し: PC24px、スマホ20px。
- 上部2列の間隔: 32px、詳細の見出し列と本文の間隔: 32px以下。
- 画像は4:3を維持し、店舗写真はcover、明示済み代替画像だけcontainとする。

## 4. 情報量と正確性

- Hot Pepper Beautyの良い点である、コンパクトな上部概要、横並びページ内メニュー、写真と短い要点、反復可能な表・セクション構造を参考にする。
- Hot Pepper固有の配色、画像、文章、アイコン、商標を複製しない。
- WordPressに存在する料金、営業時間、予約方法、アクセス、本文、特徴、承認済み口コミ、出典だけを条件付きで表示する。
- メニュー、スタッフ、設備、空席、口コミ、評価を推測で増やさない。
- 情報がないセクションやリンクは表示しない。
- 公開データ元はWordPressのままとし、Supabase非公開候補は接続しない。

## 5. 成功条件

- 順位あり・なしカードで、同じ画面幅の画像左端・店名左端が2px以内で一致する。
- 順位バッジは画像内に収まり、カードの独立列を使わない。
- PCとスマホの各画面で、見える `予約・公式情報` グループが1つだけである。
- PC店名は34px以下、スマホ店名は26px以下、上部要点は18px以下である。
- 店舗詳細上部で画像と情報が横並びになり、画像右側の空白領域を作らない。
- 横はみ出し0、CTA高さ44px以上、ページ内リンクの移動先欠落0。
- 既存のクリック計測、SEO、構造化データ、WordPress-only契約が維持される。
