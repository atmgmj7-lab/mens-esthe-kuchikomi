# Mrs.Rank UP パイロット UI 表現・素材再利用計画

## 目的

店舗担当者・お客様・運営担当者が、それぞれ次に行うことと公開範囲を迷わず確認できる画面に整える。技術名や内部状態を画面に出さない。

## 実装範囲

1. 導入ガイド、店舗用メニュー、口コミ案内、運営確認画面を日本語の操作名へ統一する。
2. 既存の公式ロゴ、口コミ見出し用SVG、紹介用バナー3サイズを再利用する。
3. 印刷用POPは有効な店頭QRが確認できた場合だけ生成し、固定の旧QR画像は使わない。
4. 掲載情報の確認画面では、公開ページを変える保存か、公開前の確認用保存か、保存できない確認だけかを明記する。

## 素材の判断

- 採用: `headless/public/images/eskomi-logo.svg`、`headless/public/images/area-hub/banner-reviews.svg`、`headless/public/downloads/eskomi-link-banner-*.svg`。
- 不採用: Library内の旧QRカードおよび旧POP。現在の店舗・URLと静的に照合できないQRを配布しないため。
- Library取得: 指定の4ファイルを作業環境へ取得しようとしたが、署名URLの403で初回・指定どおりの再試行とも失敗。権限回避や追加の再試行はしない。

## 確認

- ソース契約、型、lint、ビルドを実行する。
- 画面QAは利用可能なブラウザ環境で320px、390px、768px、1280pxを確認する。クラウド環境にブラウザがない場合は、その未実施理由を成果物に残す。
