# 開発ルール

## 厳守ルール

- **サーバー負荷軽減**: API 呼び出し前やスクレイピング間に最低 15 秒（または指定の SLEEP）の待機を入れること。

## エラー処理

- `try-except` で全体を囲み、1 店舗のエラーで全体の処理を止めないこと。
- エラー発生時はその店舗をスキップし、次の店舗へ継続すること。

## 除外設定

- 画像（jpg, png 等）や PDF へのリンクは探索対象から除外すること。
- 店舗リンク抽出時は `shop_news`, `shop_cpon`, `shop_menu` 等のサブページを除外すること。

## WP 連携

- 環境変数（`.env`）から `WP_APP_PASSWORD` 等を読み込み、コードに直接パスワードをハードコードしないこと（一時的なテスト時を除く）。
- 必須環境変数: `WP_SITE_URL`, `WP_USER`, `WP_APP_PASSWORD`
